## Why Not Appchain


Opposite to the smart contract chain, which all smart contracts run on the same chain, the appchain run every application in a separate chain. 

So the concept of appchain is one dapp on a isolated specific blockchain.

The biggest problem of appchain is its expensive maintainence costs. To bootstrap a standalone blockchain is not an easy thing. 

Every chain's critical task is to attract enough validators and staking on it. Most dapps don't have 
this kind of resources to achieve that. Even though it boots up successfully, how to reward the validators consistently is another big issue hard to overcome.

The most famous example of appchain is Axie Infinity.
 
But obviously the Appchain is not the ideal solution for most Web3 projects.
