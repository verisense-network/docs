## Why Restaking

The `nucleus` network can be run in the Verisense matrix automatically, but there are two missing parts:

1. The Verisense network itself needs to be bootstraped securly;
2. The Verisense network itself needs to have as many nodes as possible;

On the difficulty to bootstrap a new PoS network nowadays, Verisense decide to support the existing restaking protocols to smooth the boot up procedure of its network.

Verisense can use EigenLayer, Symbiotic, Karak and others as its security sources.
