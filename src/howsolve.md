## How Verisense Solves Problems


Verisense introduces a two-level heirarchy structure to solve those problems.

On the first level, there is a traditional PoS blockchain.

On the second level, there exist many `nucleus` networks. Each `nucleus` network runs a isolated light app.

The top level PoS blockchain controls the bottom level `nucleus` networks. The actual light app code run in the second level.

By this heirarchy design, Verisense offload the computation burden and storage burden to offchain, while still keeping the security of the whole network.
