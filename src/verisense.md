## What is Verisense

Verisense network is a new startup focusing on solving the problems of smart contract blockchain and application blockchains.

Verisense network supplies the solution of Light App. Developers can deploy their light apps onto the Verisense blockchain. 

Verisense network can run hundreds of Light Apps easily, each light app will run in its own container and tasks, so different light apps will not intervene each others.

Verisense works like the Matrix.
