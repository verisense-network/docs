## Why FHE

Fully Homomorphic Encryption (FHE) is a more advanced form of Homomorphic Encryption. FHE allows arbitrary computations to be carried out on encrypted data, which is not the case with normal HE which might be limited in the types of computation it supports.

For a small size of network, mere Monadring is not sufficient to keep the security of this network, it must use FHE as the core blind vote method to achieve the sufficent and reliable security.

FHE can hide the information of previous participants, so it can be used to dismiss the second order advantages.
